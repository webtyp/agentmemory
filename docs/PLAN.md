# Plan — `webtyp/agentmemory`: follow the renamed memory ports

## 0. Context

`agentmemory` implements the memory ports that `webtyp/agent` declares, over `orm` + `ddl`
(so the same code runs on SQL backends and on IndexedDB). In agent v0.6.0 the conversation
types moved to `webtyp/agentcontext` and `webtyp/llm`, and two ports were renamed:

| agent v0.5 | agent v0.6 |
|---|---|
| `AppendMessage(ctx, sid, agent.Message)` | `AppendTurn(ctx, sid, agentcontext.Turn)` |
| `GetMessages(ctx, sid, limit) []agent.Message` | `GetTurns(ctx, sid, limit) []agentcontext.Turn` |
| `DeleteMessages(ctx, sid, ids)` | `DeleteTurns(ctx, sid, ids)` |
| `SaveEpisode(ctx, sid, summary, tokens, fromID, toID)` | `SaveSummary(ctx, sid, agentcontext.Summary)` |
| `GetEpisodes(ctx, sid, limit) []agent.Episode` | `GetSummaries(ctx, sid, limit) []agentcontext.Summary` |

The caller now assigns `ID` and `CreatedAt` for turns and summaries. The store no longer
invents them: `SaveEpisode` used to call `idGen.NewID()` and `time.Now()`.

**The database schema does not change.** The `message` and `episode` models keep their names
and fields. They are this repository's storage detail, and renaming them would force a
migration of existing data for no behavioural gain. Only the mapping between rows and the
new Go types changes.

## Development rules (inline)

- Every file compiles under `GOOS=js GOARCH=wasm` and TinyGo.
- **Never import:** `database/sql` (use `orm`/`ddl`), `context` (use `webtyp.com/context`),
  `fmt`/`errors`/`strings`/`strconv` (use `webtyp.com/fmt`), `encoding/json`, `time` (use
  `webtyp.com/time`), `map[K]V`, `os`, `log`, `net/http`.
- Do **not** edit `models_orm.go` by hand. It is generated by `ormc`, and this plan does not
  touch the models.
- Tests: `testing` only. Do **not** run `gopush`/`codejob`.

## Design gate

This plan adds no public API of its own. It follows the port change designed and justified in
`webtyp/agent` v0.6.0 (see that repository's `docs/ARCHITECTURE.md`). **What it deletes:**
`AppendMessage`, `GetMessages`, `DeleteMessages`, `SaveEpisode`, `GetEpisodes`, and the
`idGen`/`time` use in the summary path.

## Stage 1 — dependencies

`go get webtyp.com/agent@v0.7.0 webtyp.com/agentcontext@v0.2.0 webtyp.com/llm@v0.1.0`. (v0.7.0 only adds
`Config.Clock`; the memory ports are the v0.6.0 ones described above.)

## Stage 2 — conversation (`conversation.go`)

- `AppendTurn(ctx, sessionID string, t agentcontext.Turn) error`: return
  `fmt.Err("agentmemory: AppendTurn: Turn.ID must not be empty")` when `t.ID == ""`. **Delete**
  the `idGen` fallback: an empty ID is the caller's bug, and filling it in would hide the bug.
  Map `Role: string(t.Message.Role)`, `Content`, `ToolName`, `ToolCallId: t.Message.ToolCallID`,
  `ToolCalls: encodeToolCalls(t.Message.ToolCalls)`, `TokenCount: int64(t.Tokens)`, `CreatedAt: t.CreatedAt`.
- `GetTurns`: same query as today's `GetMessages`, mapping rows back to
  `agentcontext.Turn{ID, Message: llm.Message{Role: llm.Role(r.Role), …}, Tokens: int(r.TokenCount), CreatedAt}`.
  Keep returning oldest-first. The contract no longer requires an order, but tests read more
  easily this way.
- `DeleteTurns`: body of today's `DeleteMessages`.

## Stage 3 — summaries (`summary.go`, replaces `episode.go`)

Delete `episode.go`. Create `summary.go`:
- `SaveSummary(ctx, sessionID string, s agentcontext.Summary) error`: error
  `agentmemory: SaveSummary: Summary.ID must not be empty` when empty. Map `Summary: s.Text`,
  `TokenCount: int64(s.Tokens)`, `FromMsgId: s.FromTurnID`, `ToMsgId: s.ToTurnID`, `CreatedAt: s.CreatedAt`.
- `GetSummaries`: today's `GetEpisodes` query, mapped to `agentcontext.Summary`.

## Stage 4 — tool calls (`tool_calls.go`)

`encodeToolCalls` / `decodeToolCalls` take and return `[]llm.ToolCall` instead of
`[]agent.ToolCall`. The encoding is unchanged, so rows already stored decode the same way.

## Stage 5 — tests

`store_test.go` already runs `webtyp.com/agent/conformance`. Bumping `agent` to v0.7.0 brings
the renamed suite, including `summary_round_trips_all_fields`. Add:
- `TestAppendTurn_EmptyIDErrors` and `TestSaveSummary_EmptyIDErrors` (exact messages above).
- `TestToolCalls_RowsFromV01StillDecode`: a hand-built row string in the v0.1 encoding decodes
  into the same `[]llm.ToolCall`.

## Stage 6 — every test in `tests/`

The ecosystem rule: tests live in `tests/` (package `tests`), so the repository root holds only
library code. Move `store_test.go` and `tool_calls_test.go` to `tests/store_test.go` and
`tests/tool_calls_test.go`, change their package clause to `package tests`, and import
`webtyp.com/agentmemory` for every symbol they use. They must use only the exported API. If a
test needs an unexported symbol, rewrite it to observe the same behavior through the exported
API (for example, save through `Store` and read back through `Store`); do not export anything
for tests, and do not add `export_test.go`.
